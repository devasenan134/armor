What I've built

Four projects: the problem, what I built, and where each one stands.

In progressAug 2026 – ongoing
Personal project

Synthetic-to-Real Domain Gap Detector

Goal: estimate how well synthetic training data will transfer to real detection before a full train/eval cycle. Built: a config-driven render → train → eval pipeline (BlenderProc, YOLOv8) over domain-randomized YCB-V variants. In progress: a no-training gap metric (FID / KID on DINOv2 features) and a drift monitor (MMD / KS-test). Results not yet published.

BlenderProcYOLOv8DINOv2FID / KID
~100Ksynthetic samples
Hyperverge · Data Engineer Intern · 2024

ID-card quality-check data

Built a Blender-based pipeline generating ~100K samples of blur, glare and partially visible cards, plus an occlusion pipeline for cases Blender couldn't simulate. Led annotation for the ID-card QC model and had vendors re-capture printed cards to close the synthetic-to-real gap. Contributed to relative reductions of ~50% FAR and ~12% FRR in the overall quality-check pipeline.

Synthetic ID-tamper dataset

Generation pipelines for a 5-class tamper dataset with pixel-level masks, using image splicing and Python-driven Photoshop automation, with per-sample configs logged so later model versions can reproduce it.

Room re-tiling pipeline

Replaces walls and floors in room photos with a chosen tile or wallpaper: text-prompted segmentation with Grounding DINO + SAM, corner extraction from layout maps (RDP, KMeans), perspective overlay and LAB/HSV lighting transfer.
